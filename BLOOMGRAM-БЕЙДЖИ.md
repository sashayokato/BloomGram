# Как выдавать бейджи пользователям BloomGram

## Что есть сейчас

| Бейдж | Кому | Как появляется |
|---|---|---|
| Создатель | `CREATOR_ID = 5853805443` (ты) | Захардкожен в `BloomBadges.kt`, виден всем пользователям приложения |
| Разработчик | кого выдашь | меню профиля → Grant developer badge |
| VIP | кого выдашь | Grant VIP badge |
| Админ | кого выдашь | Grant admin badge |
| Медиа-партнёр | кого выдашь | Grant media partner badge |

Выдавать может **только аккаунт с ID 5853805443**. У других пользователей пункты меню не появятся.
Проверка идёт по ID, а не по имени — подмена никак не прокатит.

## Как выдать в приложении

1. Войди в BloomGram под своим аккаунтом (ID 5853805443).
2. Открой чат/профиль нужного пользователя.
3. В меню «Другие» появятся пункты `Grant … badge` / `Revoke … badge`.
4. Нажми нужный — бейдж сразу появится у этого пользователя **в твоём приложении**.
5. Повторное нажатие с тем же пунктом (`Revoke`) убирает бейдж.

## Важное ограничение (читай обязательно)

Сейчас гранты хранятся в `SharedPreferences` **на твоём устройстве**. Значит:
- у тебя в приложении бейдж у пользователя виден;
- у других пользователей в их копиях приложения — **пока нет**.

Чтобы бейджи видели **все**, нужно включить общий список `GRANTS_URL`.

## Как сделать бейджи видимыми всем

### Вариант А — статический JSON (быстро)

1. В приложении (под своим аккаунтом) выдай бейджи нужным людям.
2. В `BloomBadges.kt` вызови `exportGrantsJson()` — получишь строку вида:
   ```json
   {"developers":[12345],"admins":[67890],"vip":[111],"media":[222]}
   ```
   (можно также собрать вручную — это просто ID через запятую).
3. Положи файл в публичный raw-URL, например:
   `https://raw.githubusercontent.com/sashayokato/BloomGram/main/grants.json`
4. В `BloomBadges.kt` замени:
   ```kotlin
   const val GRANTS_URL = ""
   ```
   на свой URL.
5. Пересобери APK и раздай пользователям. Клиент раз в 10 минут подтягивает файл.

### Вариант Б — свой API (лучше)

Подними endpoint, который отдаёт тот же JSON, и поставь его адрес в `GRANTS_URL`.
Тогда выдачу/отзыв можно делать через админку без пересборки приложения.
Логика уже готова: `refreshRemote()` раз в `REFRESH_MS` читает четыре массива
`developers / admins / vip / media`.

## Приоритет отображения

Одновременно показывается **один** бейдж:
`создатель → админ → разработчик → VIP → медиа-партнёр`.

## Безопасность

- Бейджи **клиентские**: в другом Telegram-клиенте их не видно. Это декорация, не серверный статус.
- ID создателя можно менять только в исходниках и пересобирать APK.
- Общий JSON подписывать нечем — не публикуй в нём чужие приватные данные, только ID.
